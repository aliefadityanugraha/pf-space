Klasifikasi Contoh Penggunaan Rencana Penanganan
A. Semantic UI Color bg-white, bg-brand-cream, text-stone-900, border-black Ganti dengan bg-background, bg-card, text-foreground, border-border atau tambahkan varian dark:.
B. Brand Color bg-brand-red (#ef4444), bg-brand-teal (#265c5c), bg-brand-orange (#fdba74) Tetap / Fixed Identity di kedua mode untuk menjaga identitas visual PF Space.
C. Artwork / Media Poster film, thumbnail video, logo institusi (/logo-perfilman.png, UDINUS, SMKN 1 Ngasem) Fixed Media (tidak diubah). Logo putih pada footer dipastikan kontras.
D. Status Color Badge status (bg-amber-100, bg-red-100, text-amber-700) Dalam .dark di style.css, warna status ini sudah di-map ke tone yang nyaman di mata gelap (--color-amber-100: #451a03).
E. Fixed Neobrutalism Elements shadow-brutal (4px 4px 0px #000) Bayangan tegas #000 khas Neobrutalism tetap dipertahankan atau menggunakan variabel --shadow-brutal-color.
