⚙️ Theme Architecture
State Engine: Singleton Composable useTheme() mengelola themeMode ('light' | 'dark' | 'system') dan isDark (boolean reaktif).
System Preference Listener: Menggunakan window.matchMedia('(prefers-color-scheme: dark)') secara reaktif. Saat mode system aktif dan OS pengguna berganti mode, aplikasi otomatis menyesuaikan tanpa perlu refresh.
Anti-Theme-Flash Guarantee: Skrip inline pada index.html mengeksekusi pemeriksaan preferensi tema sebelum browser merender CSS & JavaScript bundle, menjamin 0% Theme Flash saat initial page load.
CSS Token Source of Truth: Tetap menggunakan variabel CSS shadcn/ui dan inversi palette Tailwind v4 yang sudah dikonfigurasi di

src/style.css
.
💾 Storage Mechanism
Kunci Penyimpanan: localStorage dengan kunci 'vueuse-color-scheme' (meneruskan konvensi yang sudah ada pada proyek).
Nilai Storage: 'light', 'dark', atau 'auto' (untuk mode system).
Fallback: Jika localStorage tidak dapat diakses (misal pada mode incognito ketat), sistem secara mulus jatuh kembali (fallback) ke mode 'system'.
